Pacote público completo para Multica Desktop 0.7.2 no Windows x64. Não exige acesso a repositório privado nem login GitHub para baixar ou instalar.

Inclui 60 temas, bancada de chat, terminal com dependências incluídas, memória local, backup opcional, Início, Automações, navegação, PT-BR, Docs, Marketplace Composio, Pool e Estúdio de IA.

Baixe o ZIP, confira SHA256SUMS.txt, extraia e execute Instalar.cmd na sessão do Windows. O aplicativo Multica deve estar instalado em um build compatível. Instalações públicas anteriores podem ser atualizadas usando a mesma pasta de extensões e seu backup registrado. Builds desconhecidos são recusados.

Cada pessoa configura suas próprias contas. Não há chave, e-mail, destino de backup ou configuração pessoal do autor. Git e GitHub CLI só são necessários para os recursos que usam Git; o backup é opcional e exige informar explicitamente um repositório próprio.

Validação: 33 testes passaram; pacote montado sobre o ASAR original, aplicado e revertido em instalação isolada com igualdade de hash; 60 temas e oito marcadores de recursos verificados; terminal nativo executou comando; scripts PowerShell analisados; varredura Gitleaks do ZIP extraído sem ocorrências. Não foi validado o login/OAuth de uma conta de terceiro.

Para remover, execute Desinstalar.cmd. O repositório privado original permanece privado.
